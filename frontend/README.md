# Period Tracker - Frontend

This is the frontend application for the **Period Tracker**, a modern, privacy-focused web application designed to help users track their menstrual cycles, daily symptoms, and receive dynamic predictions for future periods and fertile windows.

## 🚀 Tech Stack

- **Framework:** React 19 (TypeScript) with Vite
- **Styling:** Tailwind CSS (v4)
- **State Management & Data Fetching:** React Query & Axios
- **Routing:** React Router v7
- **UI Components:** Radix UI, Lucide React icons
- **Animations:** Framer Motion
- **Data Visualization:** Recharts
- **Forms & Validation:** React Hook Form & Zod

## 🛠️ Getting Started

### Prerequisites
- Node.js (v18+)
- The [Period Tracker Backend](../README.md) running locally or accessible via URL.

### Installation

1. Install the dependencies:
   ```bash
   npm install
   ```

2. Start the development server:
   ```bash
   npm run dev
   ```

3. Open your browser and navigate to `http://localhost:5173` (or the URL provided by Vite).

### Build for Production

To build the application for production, run:
```bash
npm run build
```
This will compile the TypeScript code and generate static assets in the `dist` directory.
